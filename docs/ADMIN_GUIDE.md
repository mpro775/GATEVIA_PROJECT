# Administration guide

Editors create records as drafts, complete each active locale tab, attach reusable media, review SEO fields, preview, then publish. Missing translations remain unavailable publicly; the system does not silently mix languages. Archive published content instead of deleting it.

The Media Library uses direct signed uploads. Add localized alt text unless an image is marked decorative. Referenced files cannot be archived without an explicit reviewed override.

Sales users can filter leads, change status, assign owners, add private notes, and read assessments as grouped fields. Lead messages and notes are private and must not be copied into analytics.

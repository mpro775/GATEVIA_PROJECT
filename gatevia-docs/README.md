# GATEVIA V1 contract baseline

This repository-local `gatevia-docs/` directory is the canonical source of truth for GATEVIA V1 requirements, core contracts, technical contracts, acceptance criteria, and deployment guidance.

External archives are distribution snapshots only. They must be regenerated from this directory and must never overwrite newer repository-local contracts.

`../GATEVIA_MASTER_IMPLEMENTATION_PROMPT.md` remains part of the canonical contract set and is intentionally retained at the repository root for existing tooling and links.
